# 描绘 · Midjourney 提示词工作台

[下载安装包](https://github.com/1394780571zkm-coder/prompt-atelier/releases/latest) · [查看发布记录](https://github.com/1394780571zkm-coder/prompt-atelier/releases) · [MIT 许可证](LICENSE)

只想使用软件：进入上方下载页，在 Assets 中下载 `PromptAtelier-Setup-1.0.3-x64.exe`。GitHub 自动提供的 Source code 压缩包是源码，不是安装包。

Windows 桌面应用，数据保存在这个项目的 `data` 目录下。双击 `启动.cmd` 即可打开。首次安装依赖需要 Node.js 24 或更新版本和网络连接。也可以在项目目录运行 `npm ci` 和 `npm start`。

## 分享安装版

`dist/PromptAtelier-Setup-1.0.3-x64.exe` 是 Windows x64 完整安装包，内置 Electron、Node.js、DeepSeek Harness 和两套本地翻译模型，使用者无需另外安装 Node.js。安装向导可选择目录，并创建桌面和开始菜单快捷方式。

安装版的草稿、历史和图库存放在当前用户的应用数据目录，与开发目录的数据分开。分享包不包含开发者的个人记录、图片或 API Key。需要使用 DeepSeek 分类、拆分和备选生成时，使用者在设置中填写自己的 API Key；本地编辑、图库、离线分组和翻译不需要 Key。Discord 等在线图片下载仍需要可访问对应网站的网络。

开发者运行 `npm run dist:win` 可重新生成安装包。打包前需准备 `build/runtime/LICENSE`、第三方模型说明和完整的 `data/translation-models`，构建脚本会复制本机 Node.js 运行时；发布前应运行测试和安装版验证。

## 编写和复用

图片素材中的垫图、风格参考、生成结果均可点击「粘贴图片」，把复制的图片或截图追加到对应区域，并自动收藏到图库。剪贴板为空时会提示先复制图片。粘贴的图片没有公开链接，需要用于 MJ 垫图或风格参考时，可通过「补链接」添加公开图片地址。

1. 把整条 Midjourney 提示词粘贴到「草稿栏」，或点「粘贴 MJ 提示词」从剪贴板导入。开头图片链接归入「垫图」，`--sref` 图片链接归入「风格参考」，其他后缀归入参数。程序会下载可访问的图片并收藏到图库。「填入示例」提供一条内置范例。
2. 在「画面元素」里细选词条，或打开「随机组合」后点选大类。每个分支会抽一项，点击候选词条可移除。选好后点「导入到草稿」。
3. 正文下方可查看图片前缀。点击后缀标签可调整参数，点击标签右上角的 × 可移除参数。「最终提示词」显示组合结果，点「复制提示词」即可粘贴到 Midjourney。生成结果随历史归档。
4. 历史把正文和后缀参数分栏显示。打开「操作模式」后，「微调」允许临时修改正文和后缀，复制后自动回到原记录。「编辑」保存永久修改，「复用」创建新草稿。用「添加出图」补充历史记录的生成结果。
5. DeepSeek 分类产生可复用的风格包、画面词条及需要新增的分类，点击即可加入当前草稿。

历史记录卡片可单独删除，也可勾选多条或全选当前筛选结果后批量删除。删除历史记录不会删除草稿或图库图片。

草稿栏保留完整的正文输入框，下方词块随输入实时更新。正文按中英文逗号、分号和换行拆成词块，单击可点亮或点灭，双击或按 F2 可修改内容。点灭的词块保留在草稿中，切换分类或重新打开工具后仍能恢复；最终提示词、复制和保存历史只使用点亮的正文。

新建提示词保留当前选好的垫图和风格参考，只清空生成结果。导入新提示词时同样保留原参考素材；新的 `--sref` 图片会追加下载、收藏并显示，不替换已有风格参考。需要移除素材时点击对应图片的 ×。

在草稿栏上方可新建和切换提示词分类。每个分类单独保留草稿、历史记录和从已保存提示词提取的词条及风格包；拆分台的词库替换也跟随当前分类。「全部」汇总已保存内容，新写的提示词默认归入「未分类」。旧记录也归入「未分类」。

「保存到历史记录」会保存当前内容；再次点击会更新同一条记录。DeepSeek 的“提取完成”表示画面词条与风格包已分析入库，与整条提示词所属的文件夹是两件事。状态栏会分别显示所属文件夹、词条数量、类别数量和风格包内容数量；编辑后会提示“有修改待保存”。提取出的纯风格短语同时进入画面元素的对应类别和提示词库中的风格包，可整包复用。旧记录中只保存在风格包内的短语会在应用下次启动时补入画面元素，无需重新调用模型。风格包随来源历史记录保存与更新，删除来源记录也会移除它提供的词条和风格包。

鼠标停留在画面元素的非人物词条上，可以查看当前分类内使用该词条的历史图片。每条历史横向展示垫图、风格参考和生成结果，多条历史向下排列；图片可点击放大，也可展开查看和复制完整提示词。人物及其下属词条不显示图片案例。预览来自已保存的历史记录，后续补充出图后会自动更新。

输入或导入外文提示词时，正文下方会出现「中文译文」，输入暂停后自动翻译，也可以点击「翻译成中文」立即开始。翻译使用本地模型：英文为 Opus-MT，其他语言为 M2M100，不调用 DeepSeek、腾讯或谷歌翻译 API。首次使用按需下载模型，英文模型约 120 MB，其他语言的多语言模型约 640 MB。下载完成后可在本机免费翻译。继续编辑正文后会自动更新译文，失败时可点击按钮重试。译文单独显示，原文、链接和参数可继续用于 Midjourney。

在「提示词拆分台」粘贴 MJ 提示词、载入当前草稿，或从历史记录的操作模式送入。DeepSeek 根据本地分类表归组，离线时可用规则分组。每个类别以紧凑选框显示原文词条，选中后点「替换」，从同类词库、DeepSeek 备选或自定义内容中选择，再点「导入」更新下方的「全新提示词」。单击词块可点亮或点灭，双击可修改正文或参数值；正文编辑窗口也可调整词块类别，键盘 F2 同样可以编辑。外文正文词块自动生成逐项中文对照，译文不参与复制或保存。可还原全部、复制新旧提示词、将变体另存到历史，或导入编写器继续编辑。

## DeepSeek Harness

在「设置 → 智能体分类」填写 DeepSeek API Key、选择模型并保存。勾选「保存后自动分类」时，提示词先归档到本地，随后在后台更新画面词条与风格包。关闭开关后，仍可对已保存的记录点「用智能体分类」，或从历史记录手动运行、重试。API Key 使用 Windows 系统加密保存在本机，也支持环境变量 `DEEPSEEK_API_KEY`。

同一区域可查看并复制「分类提示词模板」。分类规则、层级和返回结构与当前智能体使用的版本一致。接入其他智能体时，把 `{{PROMPT_BODY_JSON}}` 替换成正文的 JSON 字符串。

## 图片和风格码

- 可将网页图片或图片链接拖入图库、垫图、风格参考或生成结果。应用保存原图链接及本地副本，浏览器同时提供来源网页时也会保存。也可以批量拖入文件或在「添加图片」里粘贴多行原图链接。
- 三个素材栏的「添加图片」都能从图库多选。带有原图地址的垫图与风格参考会进入复制出的提示词。仅提供本地文件的拖放可预览和归档，直接复制的提示词仅包含有公开链接的参考图。
- 图库里缺链接的图片会标红。垫图和风格参考也会标红，并在「最终提示词」下列出图片名。可直接把图库缩略图作为本地文件拖到 Discord 聊天框或 Midjourney 网页上传区。上传后将带地址的图片拖回原红框，或点「补链接」粘贴原图地址。
- 「补链接」弹窗中的预览可作为本地文件拖到 Discord 网页版、Postimages、Cloudinary 等网站的上传区。上传后在浏览器打开原图，从网页把图片拖回弹窗或红框。Discord 附件链接可能过期，本地副本仍可查看。
- 图库支持创建分组。打开分组后导入的图片进入该组，在「全部」视图导入的图片进入「未分类」。悬停卡片可移到其他组，或点击垃圾桶直接永久删除本地文件和草稿、历史里的对应引用，无需再次确认。
- 提示词分类会在图库中创建同名文件夹视图。分类内导入或归档的图片会显示在该文件夹；从任一分类打开图片素材选择器，仍可浏览整个图库。多个分类可以共用同一张图片。
- 鼠标停留在图库图片上，可查看这张图关联的全部历史提示词及其用途。每条记录标明垫图、风格参考或生成结果；仅用于展示的风格样图单独标注。同一图片在不同记录中的用途分别显示。
- 来源网站拒绝下载或链接失效时，应用保留粘贴的参考链接并提供「重试下载」。已下载的本地副本仍可预览。已有插画库文件和归档图片会进入新图库。
- 有数字 `--sref` 时，放到「风格参考」区域的图片默认作为这组风格码的样图。同一组风格码、模型版本和风格参考版本的记录会共用已存的样图。已有出图也可以展示为出图样例。需要给数字风格码补充样图时，可在历史里点「在 Midjourney 查找」。
- 使用 Midjourney 网页端时，可以把参考图片添加到 Imagine 栏的对应图片槽，也可从工作台复制正文及后缀。不同版本的参数按 Midjourney 官方文档使用。

备份本地历史和图片时复制整个 `data` 文件夹。换电脑后需要重新填写 API Key。

### 从源码运行

需要 Windows 和 Node.js 24 或更新版本：

```powershell
npm ci
npm test
npm start
```

首次翻译会下载所需模型。制作完整安装包前，在应用中分别完成一次英文与非英文翻译，等待两套模型下载完毕，并确认模型位于项目的 `data/translation-models` 目录。将所用 Node.js 官方发行包中的 `LICENSE` 保存至 `build/runtime/LICENSE`，保留已有第三方声明和模型说明，然后运行：

```powershell
npm run dist:win
```

构建结果位于 `dist/`。安装包通过 GitHub Releases 分发，不提交到 Git 源码历史。
